# ============================================================
# 扫描件 OCR 依赖 —— 可选
# ============================================================
# 用途：把「图片型 PDF」（扫描件、拍照件、传真件）里的文字提取出来。
# 中小企业的合同、制度、发票、证照大量是这类文件 —— 不做 OCR 就只能手工录入。
#
# 体积约 100~150 MB，**纯 CPU 可跑，不需要 GPU**，也不需要外部程序
# （如 poppler / tesseract）。不装也能正常使用，只是扫描件提不出文本。
#
# 装法：
#     pip install -r requirements-ocr.txt
#
# 装好后无需改配置 —— config.document_loader.ocr.enabled 默认为 true，
# 系统会自动对「文本过少」的页面走 OCR，并在分块 metadata 打上 ocr=true 以便溯源。
# ============================================================

# PDF 页面渲染（自带渲染引擎，无需 poppler / Ghostscript）
pymupdf>=1.24.0

# OCR 识别：基于 onnxruntime，比 PaddleOCR 轻得多，安装无编译负担
rapidocr-onnxruntime>=1.3.0
