======================================================
知阁 Zhige - 本地单用户模式说明
======================================================

✓ 当前配置: 本地单用户模式（开箱即用）

config/config.yaml:
  auth:
    enabled: false  ← 默认设置，无需登录

======================================================
使用方式
======================================================

1. 启动系统:
   python scripts/quickstart.py

2. 打开浏览器:
   http://localhost:8000

3. 直接使用，无需注册登录！

======================================================
工作原理
======================================================

- 所有请求自动使用"本地用户"身份
- 本地用户 ID: 00000000-0000-0000-0000-000000000001
- 权限级别: enterprise（无配额限制）
- 数据保存在本地: data/ 目录

======================================================
适用场景
======================================================

✓ 个人开发者本地使用
✓ 单机部署（一人一机）
✓ 内网私有化（信任所有访问者）
✓ 快速测试和原型开发

======================================================
如需多用户模式
======================================================

方式一: 修改配置文件
  config/config.yaml → auth.enabled: true

方式二: 环境变量（推荐）
  Windows: set AUTH_ENABLED=1
  Linux:   export AUTH_ENABLED=1

然后重启服务。

======================================================
检查当前模式
======================================================

python check_auth_mode.py
