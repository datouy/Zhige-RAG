# ============================================================
# ChineseRAGKB 依赖总表
# ============================================================
# 本文件通过 -r 引用分组文件，是"全量安装"的入口。
# 各分组才是依赖的唯一真实来源，避免同一份清单在多个文件里漂移。
#
# ⚠️ 不建议无脑全量安装 —— 光 torch 就有 2~3 GB。按需选择：
#
#   【最快跑起来，完全不需要 GPU】用 Ollama 或云端 API 作为模型后端
#       pip install -r requirements-core.txt
#       pip install -r requirements-optional.txt     # 需要解析 PDF/Word 时
#
#   【完全本地推理（无网 / 数据不出内网）】
#       pip install -r requirements-core.txt -r requirements-local.txt
#
#   【有 NVIDIA GPU，想用 4bit 量化省显存】
#       pip install -r requirements-gpu.txt          # 单独装，见文件内说明
#
#   【开发与测试】
#       pip install -r requirements-core.txt -r requirements-dev.txt
#
# 装完请执行环境自检，它会直接告诉你还缺什么、模型能不能用：
#       python scripts/doctor.py
# ============================================================

-r requirements-core.txt
-r requirements-local.txt
-r requirements-optional.txt

# 说明：requirements-gpu.txt（bitsandbytes）未纳入本文件 ——
# 它只在 NVIDIA CUDA 环境可用，纳入后会让大量 CPU / Windows 机器安装失败，
# 属于"开箱即用"的硬伤。需要时显式安装：pip install -r requirements-gpu.txt
#
# 开发依赖（pytest / ruff）同样不纳入：pip install -r requirements-dev.txt
